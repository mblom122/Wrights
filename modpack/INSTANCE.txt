Wrights isolated test instance
=============================

This folder is a mod list for a NeoForge 1.21.1 instance used to test Wrights before it goes into a large pack.

Fastest way to play that instance:

    gradlew runClient

That downloads Minecraft 1.21.1, NeoForge, Curios, JEI, Jade, Applied Energistics 2, GuideME, Mekanism, and Framed Blocks, then opens the game.
Jade is the tooltip that names whatever you look at. On a wright it also shows the tier and the build in progress.
AE2 19.2.18 needs GuideME 21.1.22. Mekanism is 10.7.19.85. Framed Blocks is 10.6.3. None of those are required to play Wrights.
Do not copy All the Mods into the run folder while you are still testing.

Launcher instance:

1. Install NeoForge 21.1 for Minecraft 1.21.1.
2. Create a new empty instance. Do not add the ATM10 Aeronautics pack.
3. Run: gradlew isolatedPack
4. Copy modpack/mods/wrights-0.1.0.jar into that instance's mods folder.
5. Install Curios (required) and Jade 15.10.6 for NeoForge 1.21.1 beside it, so the wright tooltip can be tested.
6. To test storage, machinery, and framed blocks, also install Applied Energistics 2 19.2.18, GuideME 21.1.22, Mekanism 10.7.19.85, and Framed Blocks 10.6.3 for NeoForge 1.21.1.
7. Leave every other mod out. Jade, AE2, GuideME, Mekanism, and Framed Blocks are not inside the Wrights jar.
